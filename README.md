# Retail Sales Intelligence & Profitability Analysis

## Project Overview
This project analyzes retail sales data to identify sales trends, profitability patterns, regional performance, category performance, and the impact of discounts on profit.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- SQL
- SQLite
- Microsoft Power BI

## Dataset
The project uses the Sample Superstore dataset containing 9,994 rows and 21 columns, including order details, customer segments, regions, product categories, sales, discounts, and profit.

## Project Workflow
1. Inspected and analyzed the dataset using Python and Pandas.
2. Analyzed sales, profit, categories, regions, subcategories, and discounts.
3. Created visualizations using Matplotlib.
4. Loaded the dataset into an SQLite database.
5. Executed SQL queries to answer business questions.
6. Built an interactive Power BI dashboard.

## Key Findings
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Unique Customers: 793
- Overall Profit Margin: 12.47%
- Technology generated the highest category profit.
- The West region generated the highest regional profit.
- Tables, Bookcases, and Supplies recorded losses among the lowest-profit subcategories.
- Higher discount groups were associated with negative profit in this dataset.

## Project Outputs
- Processed dataset
- SQLite database
- SQL query results
- Python-generated charts
- Power BI dashboard

## Objective
To use data analytics tools to transform retail transaction data into useful business insights and support better sales and profitability decisions.
